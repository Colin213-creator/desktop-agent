# 演示脚本

六个场景，从「能动手」递进到「能证明自己没做完」。每场都写清楚成功判据和翻车应对。

## 场景 1：能动手（约 1 分钟）

**开场**：「先让它做一件最简单的事。」

```powershell
python -m desktop_agent "打开计算器，算一下 1234 乘以 5678" --live
```

**预期**：打开计算器 → 输入 1234 → 乘 → 输入 5678 → 等号。
**成功判据**：计算器显示 7006652。
**翻车应对**：若计算器没启动，改问「记事本里输入 hello」，证明动作链路本身可用。

## 场景 2：跨应用（约 2 分钟）

```powershell
python -m desktop_agent "找出 D 盘最大的 5 个文件，整理成表格保存到桌面" --live
```

**成功判据**：桌面出现结果文件，内容与 `find_largest_files` 的返回一致。
**看点**：需要工具调用 + 文件写入 + 保存对话框。

## 场景 3：查规范再动手（约 2 分钟）

先导入 SOP：

```powershell
python -c "from pathlib import Path; from desktop_agent.memory.knowledge import KnowledgeBase; print(KnowledgeBase(Path('knowledge/index')).ingest(Path('knowledge/demo/sop-travel.md')))"
```

再提问：

```powershell
python -m desktop_agent "按照差旅报销规范生成一份报销单" --live
```

**成功判据**：生成的单据包含"住宿每晚不超过 500 元"这条来自 SOP 的限制。
**看点**：这条限制只写在文档里，不在代码里；关掉检索就做不出来。

## 场景 4：验证陷阱（约 3 分钟，最能加分）

**做法**：人为制造"看着完成、其实没完成"的局面——例如让保存对话框弹出但不点确认。

**观察**：它是宣布成功，还是发现对话框仍在、继续处理？

**看点**：单体智能体常见的错误是"操作做了就算完成"。独立 Verifier 只看截图证据，
能把这种情况判成 `replan`。

**话术**：「大部分作业在演示'我做到了'，这个演示的是'我知道自己什么时候没做到'。」

## 场景 5：学会一次（约 2 分钟）

1. 第一次跑同类任务，记录步数。
2. 把轨迹存入技能库。
3. 换一个目标再跑一次，观察步数是否下降。

**话术**：「第一次 15 步，第二次 4 步——它把经验存下来了。」

## 场景 6：远程代操作（约 2 分钟）

```powershell
python -c "from desktop_agent.remote.server import create_remote_app; ..."
```

从另一台设备或手机浏览器提交任务，被控端执行并回传状态。

**话术**：「最初想做的是人远程操控电脑，后来发现让 AI 代你操作更有价值，于是两条线合成了一条。」
